Where do I find this?
  1. Open analytics.google.com and choose (or create) the property for this site.
  2. Go to Admin → Data collection and modification → Data streams.
  3. Open the Web stream for your domain (add one if there is none).
  4. Copy the Measurement ID at the top right and paste it here.

Page views are sent automatically on every screen. Events sent: search, view_driver, view_package, begin_ride_request, ride_requested, quote_accepted, booking_cancelled, review_submitted, login, sign_up, subscription_checkout, ad_impression, ad_click. No names, phone numbers or e-mail addresses are ever included.

Where do I find the tag ID and the labels?
  1. In ads.google.com go to Goals → Conversions → Summary and create a conversion action of type Website for each row above you want to track (choose “Add a conversion action manually”).
  2. Open the action, choose Tag setup → Install the tag yourself.
  3. In the event snippet you will see a line like 'send_to': 'AW-1234567890/AbC-D_efG-h12'.
  4. The part before the slash is the tag ID (same for all actions). The part after the slash is that action’s label.

You do not need to paste any snippet into the site — these two values are all it takes.

What else does AdSense need?
  1. Your site must be approved in adsense.google.com → Sites.
  2. Create a Display ad unit for each position (Ads → By ad unit) and copy its data-ad-slot number here.
  3. Add your seller line to ads.txt on the web server — the file is already there with instructions inside (apps/web/public/ads.txt).
